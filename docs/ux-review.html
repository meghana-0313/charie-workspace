Charie UX review: before / after

Each pair sits side by side at the same width - no scrolling hunt. Panels are rendered mock panels built from the actual before/after design tokens and component structure (sandbox has no browser capture; this is labeled honestly, not presented as screenshots). Open this file in any browser.
